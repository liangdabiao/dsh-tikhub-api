# dsh-tikhub-api · TikHub API 助手

DeepSeek Harness（dsh）插件：**TikHub 多平台社交媒体数据 API** 的搜索与调用技能（抖音/TikTok/小红书/Instagram/YouTube/Twitter/Reddit/B站/微博/知乎 12+ 平台，400+ 端点）。

技能来自 [tikhub_api_skill](https://github.com/liangdabiao/tikhub_api_skill)（liangdabiao）。

## 使用

需要 [TikHub](https://www.tikhub.io) token（Configuration 填写或环境变量传入）。
